# ProtonVPN API Explorer 

**Unofficial, real‑time ProtonVPN server  stats and Api.**

Pick the fastest, least‑loaded ProtonVPN server *right now*  using data, not vibes.




## TL;DR

- This exposes **live servers info** via a simple API

Built for dashboards, scripts, bots, and people who hate guessing.



## Why this exists 

ProtonVPN doesn’t expose an official public API for live server quality.

So people either:

- connect blindly
- hard‑code server IDs
- or manually refresh the app hoping for the best

This project **collects publicly available server metadata** and exposes it through a clean REST API so you can:

- auto‑select the best server
- visualize congestion
- build monitoring or alerts
- stop reconnecting five times in a row

No login. No credentials. No magic.

***

## Features

- ⚡ **Live server availability & full server information**
- 📊 **Real‑time load & performance metrics**
- 🌍 **Country , region, ip, location, etc  filtering**
- 🔌 **Simple REST API (curl‑friendly)**
- 🛡️ **Read‑only, no account access**
